Step 1: Setup Шаг 1: Подготовка

FHIR provides some official API code libraries in Java and .NET to help you work with the standard.

They are:

Java

HAPI FHIR library: To get started with HAPI, add the dependency via Maven or Gradle - or download the library from the releases page. For R4, include all non-hapi jars in your classpath, and the following HAPI jars: hapi-fhir-base, hapi-fhir-structures-r4, hapi-fhir-validation-resources-r4.

To run the Java examples you need a Java Development Kit (JDK); current HAPI FHIR releases require JDK 17 or newer.

Microsoft .Net

FHIR .NET SDK: The simplest way to get started with the .NET SDK is to search for it in the NuGet package manager built into Visual Studio. Right click your Solution and select 'Manage NuGet Packages' and then search for and install 'Hl7.Fhir.R4'. You can find a C# project here on GitHub that contains C# examples.

Для FHIR существуют официальные библиотеки API на Java и .NET, которые помогают работать со стандартом.

Вот они:

Java

Библиотека HAPI FHIR: чтобы начать работу с HAPI, добавьте зависимость через Maven или Gradle — или скачайте библиотеку со страницы релизов. Для R4 добавьте в classpath все jar-файлы, не относящиеся к HAPI, а также следующие jar-файлы HAPI: hapi-fhir-base, hapi-fhir-structures-r4, hapi-fhir-validation-resources-r4.

Актуальные версии HAPI FHIR требуют Java 17 или новее.

Microsoft .NET

FHIR .NET SDK: проще всего начать работу с .NET SDK, найдя его в менеджере пакетов NuGet, встроенном в Visual Studio. Щёлкните правой кнопкой мыши по решению (Solution), выберите 'Manage NuGet Packages', затем найдите и установите пакет 'Hl7.Fhir.R4'. Проект с примерами на C# можно найти на GitHub здесь.
